Historical icons were obtained from the 98.js repository, React95's icon collection and Alex Meub's Windows icon archive. These are provenance sources, not a grant of a permissive license to Microsoft's imagery. The retained 98.js README describes that project as source-available/unlicensed. React95's MIT notice explicitly excludes Windows-related images. No asset-specific permissive license was identified for the Alex Meub archive.
